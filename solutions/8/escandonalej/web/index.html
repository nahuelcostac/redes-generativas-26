Quita el fondo de una imagen

Elige una imagen para aislar el elemento principal. El modelo se descarga la primera vez y procesa la imagen en este navegador.

Descargar PNG

Selecciona una imagen para empezar.

Prueba con un ejemplo: Ilustraciones SVG creadas para esta práctica.

Formatos admitidos: PNG, JPEG, WebP y AVIF. Máximo: 12 megapíxeles y 4096 px por lado. El navegador puede imponer límites menores según la memoria disponible.

Cómo usarla

Selecciona una imagen y pulsa «Eliminar fondo». La primera ejecución descarga el modelo; después, el procesamiento se realiza localmente. Revisa los bordes antes de descargar. La segmentación puede borrar partes del sujeto o conservar restos del fondo, sobre todo en escenas complejas.
