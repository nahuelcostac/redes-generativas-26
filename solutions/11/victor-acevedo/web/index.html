Qué hace el modelo

Más resolución, con límites

Swin2SR ligero amplía cada lado ×2. Estima detalles a partir de lo aprendido. Puede suavizar texturas, crear halos o dejar uniones entre bloques. No garantiza recuperar la información original.

Requisitos y formatos

Navegador moderno con WebAssembly, conexión para la primera descarga y memoria disponible. Entrada de 8 a 256 px por lado. Se usa el primer fotograma y la transparencia se compone sobre blanco. Salida PNG opaca.

Un experimento repetible

Modelo Swin2SR lightweight ×2, fp32, CPU con WASM. Transformers.js 4.3.1. Consulta el código y las comprobaciones en el repositorio.
