Lo que entiende Whisper

Inteligibilidad de todos los audios

Tasa de error de palabras (WER) entre el texto original y la transcripción de Whisper. 0 % significa que Whisper reconoce todas las palabras. Pulsa una celda para cargarla en la configuración A.

En «Números escritos con letras» Whisper escribe los números con cifras. Gran parte de ese error viene de la comparación y no del audio. Lee sus transcripciones.

Modelo, parámetros y equipo

Probar en local

El script acepta un texto, una velocidad, dos niveles de ruido y una semilla. Guarda un WAV y un JSON con todos los datos. 

python generate.py --text "Hola, esto es una prueba." \
  --speaking-rate 1.0 --noise-scale 0.667 --seed 42 \
  --output ../results/mi-ejemplo.json
